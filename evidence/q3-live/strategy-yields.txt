Q3 AFL++ live strategy-yield evidence
====================================

Purpose
-------
This file preserves the exact AFL++ UI strategy-yield rows captured from fresh
supplementary Q3 runs. AFL++ does not natively write these rows into
fuzzer_stats or plot_data; those files are preserved beside the transcripts as
supporting campaign context.

Report-use note
---------------
Use these as supplementary Q3 evidence, not as replacements for the canonical
30-minute Q4/Q7 campaign metrics. Cite fuzzer_stats and plot_data only for run
context; cite the transcripts and this file for the strategy-yield rows.
